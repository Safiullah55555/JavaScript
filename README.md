# JavaScript Learning Journey

This repository documents some of my **actual JavaScript learning process** — including **mistakes, fixes, and real comparisons**.
It is **not** a polished tutorial repo. It's about how much JS you need to start Reactjs and Nodejs, **if you understand this file you are ready to move on** .

The goal is honesty: showing *how* understanding evolved, not just the final answers.

### 2️⃣ `actual-comparisons.js`

This file contains **ONLY explicit bad → good comparisons**.

Rules followed in this file:

* Included **only** where an earlier approach was replaced by a better one
* No inferred or assumed best practices
* No patterns added later without comparison

Examples of what appears here:

* Broken `if/else` → corrected structure
* Weak loop control → `while(true)` with `break`
* Guessing game without hints → guessing game with hints
* Promise chaining → `async/await`
* Async code without safety → `try/catch`

This file answers:

> *“What did I clearly improve, and why?”*

## 🧠 How to Study This Repo

Recommended order:

1. Read `javascript-notes.js` top to bottom

   * Don’t run everything at once
   * Remove comments from code line you want to run in console.
   * Add html file, link it and run it in web console
   * Read comments carefully

2. Then read `actual-comparisons.js`

   * Focus on *why* the second version is clearer

3. Re‑implement selected sections yourself
